# Hello Flask App

A minimal Flask web application that serves a single page saying "Hello from Ciaran".

## Requirements

- Python 3.9+
- pip

## Installation

1. Create and activate a virtual environment:

   ```powershell
   python -m venv venv
   venv\Scripts\activate
   ```

2. Install dependencies:

   ```powershell
   pip install -r requirements.txt
   ```

## Running the app

```powershell
python app.py
```

Then open `http://127.0.0.1:5000/` in your browser. You should see a page saying "Hello from Ciaran".
